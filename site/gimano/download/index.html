CARA PASANG · HOW TO INSTALL

Tiga langkah mudah

1

Muat turun fail

Tekan Muat turun APK di telefon Android anda. Fail gimano-0.1.0.apk disimpan dalam folder Muat Turun.

Tap the download button on your Android phone.

2

Benarkan pemasangan

Jika diminta, buka Tetapan → Pasang apl tidak diketahui dan benarkan untuk pelayar anda (contohnya Chrome).

If asked, allow "Install unknown apps" for your browser.

3

Buka & pasang

Buka fail yang dimuat turun, tekan Pasang, kemudian Buka. Selesai!

Open the downloaded file, tap Install, then Open.

Gimano belum ada di Google Play, jadi Android mungkin memberi amaran tentang apl dari luar Play Store. Semak checksum di bawah jika anda mahu kepastian. Gimano is not on Google Play yet, so Android may warn about apps from outside the Play Store; verify the checksum below if you want to be sure.

SAHKAN FAIL · VERIFY THE FILE

Pastikan fail tidak diubah

SHA-256 · gimano-0.1.0.apk [SHA-256 akan diisi]

Semak sendiri · Check it yourself

Windows (Command Prompt / PowerShell):

certutil -hashfile gimano-0.1.0.apk SHA256

macOS / Linux:

shasum -a 256 gimano-0.1.0.apk

The result must match the SHA-256 shown here exactly. If it doesn't, don't install it.
